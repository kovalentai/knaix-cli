# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately. Do **not** open a
public issue, pull request, or discussion for a suspected vulnerability.

Email: **security@kovalentai.com**

Include a description of the issue, the affected version (`knaix
--version`), and reproduction steps where possible. We aim to
acknowledge reports within 3 business days and will keep you informed as
we work on a fix.

## Supported versions

The most recent released version of the Knaix CLI receives security
updates. Older versions are not maintained.
